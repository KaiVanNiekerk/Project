# EKVAE Honours Project Proposal

## 1. Project Focus

This project studies how to learn nonlinear dynamical systems from partial observations using deep state-space models, with Extended Kalman Variational Autoencoders (EKVAEs) as the main method.

The first objective is to reproduce the central findings of *Latent Matters: Learning Deep State-Space Models* on the paper's own benchmark settings. The goal is trend-level agreement and checks of the main parts rather than exact one-to-one numeric replication.

If the paper's results were obtained mainly on toy data or short sequences, that should be treated as a useful but limited baseline. The first stage of the project is therefore paper-faithful reproduction, while harder or longer datasets are later stress tests of generalisation.

Core questions:

- When does EKVAE outperform related sequential latent-variable models?
- Does constrained optimisation improve system identification compared with standard ELBO training?
- How stable are the gains when we move from short, structured sequences to noisier or longer-horizon data?
- Which parts matter most: the latent dynamics, the inference method, or the prior structure?

## 2. Motivation

In many real systems, we do not observe the full system state directly—only noisy signals generated by that hidden state. A good model must do more than reconstruct data; it should infer latent dynamics that are physically meaningful and useful for prediction.

A wearable health tracker, for example, observes noisy heart-rate and motion signals but not the true latent physiological state (fatigue, stress, recovery). Models that only minimize reconstruction error fit short windows well but fail to track real state evolution over time. A state-space model is valuable because it estimates hidden state forward in time and carries uncertainty, which supports safer decisions.

Similarly, a portfolio risk system observes market data (prices, returns, volume) but not true market regime (calm, transition, stressed). Models that fit short-term price movements may miss regime shifts and underestimate risk. A state-space approach can infer latent regime dynamics and propagate uncertainty, useful for risk control and stress testing.

However, strong performance on clean physical systems does not automatically transfer to real-world data. Short toy sequences can exaggerate a method's strengths; longer, noisier series reveal limits. Finance and similarly messy datasets should be treated as harder generalization checks rather than direct substitutes for paper benchmarks. The practical value lies in better forecasting from partial observations, more interpretable latent states than black-box features, and clearer understanding of where methods break down on unstructured data.

## 3. Key Concepts

This section outlines the main technical ideas.

### 3.1 DSSM (Deep State-Space Model)

A probabilistic sequence model with hidden state dynamics and an observation model. It separates how state evolves from how observations are generated.

$$
p(x_{1:T}, z_{1:T} \mid u_{1:T}) = p(z_1)\prod_{t=2}^{T} p(z_t \mid z_{t-1}, u_{t-1})\prod_{t=1}^{T} p(x_t \mid z_t)
$$

Here, $p(z_1)$ is the starting prior over the hidden state, $p(z_t \mid z_{t-1}, u_{t-1})$ is the transition model giving how the hidden state changes over time, and $p(x_t \mid z_t)$ is the observation model. The product notation repeats the same transition and observation step through the whole sequence. This factorization serves as the base framework for all compared models, supporting both prediction and system identification.

### 3.2 Kalman Filter and Kalman Smoother

A Kalman filter estimates hidden state over time from noisy observations. At each time step it performs two operations: (1) Predict using the dynamics model to estimate where the hidden state should move next, and (2) Update by correcting that prediction using the new observation, weighted by uncertainty. If the model is uncertain but the sensor is reliable, the update trusts the observation more; if the sensor is noisy, it trusts the prediction more. A Kalman smoother uses the full sequence to refine these estimates.

For linear-Gaussian systems, the dynamics and observation have the form:
$$z_t = A z_{t-1} + B u_{t-1} + q_t, \quad q_t \sim \mathcal{N}(0,Q)$$
$$x_t = H z_t + r_t, \quad r_t \sim \mathcal{N}(0,R)$$

The prediction step is:
$$\hat{z}_{t|t-1} = A\hat{z}_{t-1|t-1} + Bu_{t-1}, \qquad P_{t|t-1} = AP_{t-1|t-1}A^\top + Q$$

The update step is:
$$K_t = P_{t|t-1}H^\top(HP_{t|t-1}H^\top + R)^{-1}$$
$$\hat{z}_{t|t} = \hat{z}_{t|t-1} + K_t(x_t - H\hat{z}_{t|t-1}), \qquad P_{t|t} = (I - K_tH)P_{t|t-1}$$

When dynamics or observations are nonlinear, the Extended Kalman Filter (EKF) locally linearizes them and applies the same predict-update logic. EKVAE extends this idea by using learned linearization rather than analytic Jacobians, allowing it to work with deep, flexible dynamics. The Kalman filtering framework provides a clear way to estimate hidden states under uncertainty and forms the core inference idea behind EKVAE's latent state estimation, which helps explain why EKVAE may recover dynamics better than purely RNN-based inference methods.

### 3.3 VAE, KVAE, EKVAE

Variational Autoencoders (VAE) are latent-variable generative models trained with an encoder-decoder and ELBO objective. Kalman Variational Autoencoder (KVAE) extends VAE to sequential settings by combining VAE-style observation modeling with Kalman-structured latent dynamics. Extended Kalman VAE (EKVAE) further extends KVAE with extended-Kalman-style latent inference and neural linearisation of nonlinear dynamics. This progression shows why EKVAE should improve dynamics learning in partially observed systems: it combines flexible observation modeling from VAE with principled, uncertainty-aware Kalman filtering for the latent dynamics.

### 3.4 ELBO, Distortion, and Rate

The ELBO is the variational objective used to train latent-variable models when exact likelihood is intractable:

$$
\log p(x_{1:T} \mid u_{1:T}) \geq \mathcal{F}_{\text{ELBO}} = -D - R
$$

where $D$ is the reconstruction or distortion term and $R$ is the rate term measuring divergence between the learned posterior and prior:

$$
D = -\mathbb{E}_{q_\phi(z_{1:T} \mid x_{1:T},u_{1:T})}\left[\log p_\theta(x_{1:T} \mid z_{1:T})\right], \quad
R = \mathrm{KL}\left(q_\phi(z_{1:T} \mid x_{1:T},u_{1:T})\;\|\;p_\psi(z_{1:T} \mid u_{1:T})\right)
$$

The core trade-off is to maximize reconstruction quality ($D$ measures this) while keeping the learned posterior-prior mismatch ($R$) under control. This basic rate-distortion trade-off is used throughout the method. In this project, ELBO serves as the baseline training target for comparison, and a key claim to test is whether good ELBO alone ensures correct latent dynamics.

### 3.5 Constrained Optimisation (CO)

A training reformulation that enforces reconstruction quality and then focuses on compression related to dynamics:

$$
\min_{\theta,\psi,\phi} R \quad \text{subject to} \quad D \le D_0
$$

This is solved via the equivalent Lagrangian:

$$
\mathcal{L} = R + \lambda(D - D_0), \quad \lambda \ge 0
$$

Here $D_0$ is the target distortion level, the model is asked to keep distortion below that target while reducing the rate term, and $\lambda$ is the penalty weight that enforces the constraint during training. This gives a more controlled version of the ELBO trade-off. CO is the main mechanism tested against standard ELBO/annealing training in this project.

### 3.6 VHP (Variational Hierarchical Prior)

A learnable, hierarchical prior over initial latent states designed to better match the latent-state structure in the data:

$$
p_{\psi_0}(z_1) = \int p_{\psi_0}(z_1 \mid \zeta)p(\zeta)\,d\zeta
$$

Here $z_1$ is the initial latent state, $\zeta$ is a higher-level variable that shapes the prior over $z_1$, and the integral marginalizes over $\zeta$. This makes the starting prior more flexible than a single fixed Gaussian. In this project, VHP reduces over-regularisation and helps avoid unrealistic initial-state sampling, improving latent dynamics learning.

### 3.7 EKVAE Latent Transition

State-dependent locally linear Gaussian transition used for latent Kalman-style filtering and smoothing:

$$
p_\psi(z_{t+1} \mid z_t,u_t)=\mathcal{N}\left(z_{t+1} \mid F_\psi(z_t,u_t)z_t + B_\psi(z_t,u_t)u_t,\;Q_\psi(z_t,u_t)\right)
$$

The next hidden state is modeled as a Gaussian distribution where the mean is built from the current hidden state and the control input. $F_\psi$ controls how the current state affects the next state, $B_\psi$ controls how the control input affects the next state, and $Q_\psi$ is the covariance describing the uncertainty in the transition. This core EKVAE mechanism enables nonlinear dynamics modelling with uncertainty handling.

### 3.8 Evaluation Metrics

Two metrics evaluate the model's performance. Prediction accuracy is measured using mean squared error:

$$
\mathrm{MSE} = \frac{1}{NT}\sum_{n=1}^{N}\sum_{t=1}^{T} \lVert \hat{x}_t^{(n)} - x_t^{(n)} \rVert_2^2
$$

where $\hat{x}_t^{(n)}$ is the model's prediction and $x_t^{(n)}$ is the true value. The squared difference measures how far the prediction is from the truth, and averaging over all sequences and time steps gives one overall error score.

Latent-state identifiability is measured using the coefficient of determination:

$$
R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2
$$

where $y_i$ is the true target value, $\hat{y}_i$ is the predicted target value, and $\bar{y}$ is the average of the true target values. The numerator measures prediction error and the denominator measures the total variation in the true values. A higher $R^2$ means the latent variables line up better with the known underlying state. In this project, MSE checks rollout prediction quality, while $R^2$ checks whether learned latent variables align with known physical states.

## 4. Scope and Dataset Strategy

Current model scope:

- EKVAE (primary focus)
- One standard DSSM-style baseline
- One Kalman-family baseline
- One additional recurrent/state-space baseline only if needed for comparison

Immediate scope:

- Reproduce the paper on the original toy/controlled datasets first.
- Treat exact numeric match as unrealistic; evaluate trend-level agreement and component effects.
- Keep the first model set narrow so debugging stays manageable.

Datasets and strategy:

The paper datasets are useful for validation because they are controlled and interpretable. We target trend-level agreement and main effect reproduction rather than exact numeric match. The first phase focuses on paper-faithful reproduction with these benchmarks (pendulum images at 16x16 with sequence length 15, reacher angles with sequence length 30, and reacher RGB at 64x64 with sequence length 30). 

Harder, longer, or noisier datasets are later stress tests of generalization. If the source experiments used short sequences, they represent a limited rather than general test of the method. We prefer longer sequences or noisier real-world series as later validation checks, and treat finance or similar datasets as robustness tests rather than primary benchmarks.

Time and resource constraints may require prioritizing EKVAE with the strongest baselines first, expanding only if paper results are stable and interpretable.

## 5. Implementation Strategy

The project will follow a staged implementation approach:

1. Finalize theory and notation for consistency.
2. Establish minimum reproducible scope (core models and initial dataset).
3. Build an end-to-end baseline pipeline.
4. Add CO, then EKVAE, then VHP as a later component.
5. Run paper-aligned comparisons using MSE and latent-state checks.
6. Test on a small set of harder datasets to evaluate generalization beyond the paper setting.

## 6. Project Timeline

**Stage 1: Planning** — Define research questions, core concepts, scope, and initial methodology.

**Stage 2: Core Implementation** — Build an end-to-end baseline pipeline and produce initial comparative results on the paper datasets.

**Stage 3: Generalization Testing** — Run a small set of harder datasets as stress tests, then consolidate findings and assess limitations.

**Stage 4: Reporting** — Write the final analysis and prepare figures and summaries for presentation.

## 7. Expected Limitations

The method is likely to perform well on structured short sequences but worse on longer, noisier data. Toy benchmarks like pendulum and reacher may not generalize to harder real-world datasets such as finance. Results from controlled benchmarks should not be treated as proof of broad generalization; poor performance on harder data may reflect dataset difficulty rather than a broken implementation. We will treat such findings as informative about method limits rather than implementation failures.
