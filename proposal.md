# EKVAE Honours Project Proposal

## 1. Project Focus

This project studies how to learn nonlinear dynamical systems from partial observations using deep state-space models, with Extended Kalman Variational Autoencoders (EKVAEs) as the main method.

The first objective is to reproduce the central findings of *Latent Matters: Learning Deep State-Space Models* on the paper's own benchmark settings. The goal is trend-level agreement and checks of the main parts rather than exact one-to-one numeric replication.

If the paper's results were obtained mainly on toy data or short sequences, that should be treated as a useful but limited baseline. The first stage of the project is therefore paper-faithful reproduction, while harder or longer datasets are later stress tests of generalisation.

Core questions:

- When does EKVAE outperform related sequential latent-variable models?
- Does constrained optimisation improve system identification compared with standard ELBO training?
- How stable are the gains when we move from short, structured sequences to noisier or longer-horizon data?
- Which parts matter most: the latent dynamics, the inference method, or the prior structure?

## 2. Motivation

In many real systems, we do not observe the full system state directly. We only observe noisy signals generated by that hidden state. In this setting, a model should do more than reconstruct data: it should infer latent dynamics that are physically meaningful and useful for prediction.

Health example:

Consider a wearable health tracker. It observes noisy heart-rate and motion signals, but not the true latent physiological state (fatigue, stress, recovery). A model that only minimizes reconstruction error may fit short windows well but fail to track real state evolution. A state-space model is valuable because it estimates hidden state over time and carries uncertainty forward, which can support safer decisions.

Finance example:

Consider a portfolio risk-monitoring system. We observe noisy market variables (prices, returns, volume, volatility proxies), but the true latent market regime (for example calm, transition, stressed) is not directly observed. A model that only fits short-term price movements may miss regime shifts and underestimate risk. A state-space approach can infer latent regime dynamics and propagate uncertainty, which is useful for risk control, stress testing, and more robust decision-making.

Practical caution:

- Strong performance on a clean physical system does not automatically transfer to a market series.
- Short toy sequences can make a model look better than it will on longer, noisier time series.
- Finance and similarly messy datasets should therefore be treated as harder generalisation checks, not as direct substitutes for the paper benchmarks.

Practical value:

- Better forecasting from partial/noisy observations.
- Latent states that are more interpretable than pure black-box features.
- Improved model-based decision support.
- A clearer view of where the method breaks down when the data becomes less structured.

## 3. Key Concepts and Formulae

This section summarises the main concepts and equations used in the proposal.

### 3.1 DSSM (Deep State-Space Model)

Definition:

A probabilistic sequence model with hidden state dynamics and an observation model. It separates how state evolves from how observations are generated.

Formula:

$$
p(x_{1:T}, z_{1:T} \mid u_{1:T}) = p(z_1)\prod_{t=2}^{T} p(z_t \mid z_{t-1}, u_{t-1})\prod_{t=1}^{T} p(x_t \mid z_t)
$$

In this project:

- Base framework for all compared models.
- Supports system-identification analysis, not just raw prediction.

### 3.2 Kalman Filter and Kalman Smoother (Basics)

Definitions:

- A Kalman filter estimates a hidden state over time from noisy observations.
- A Kalman smoother uses the full sequence to refine those estimates.

Intuition:

At each time step, the filter does two things:

1. Predict: use the dynamics model to estimate where the hidden state should move next.
2. Update: correct that prediction using the new observation, weighted by uncertainty.

If the model is uncertain but the sensor is reliable, the update trusts the observation more. If the sensor is noisy, it trusts the prediction more.

Basic linear-Gaussian form:

$$
z_t = A z_{t-1} + B u_{t-1} + q_t, \quad q_t \sim \mathcal{N}(0,Q)
$$

$$
x_t = H z_t + r_t, \quad r_t \sim \mathcal{N}(0,R)
$$

Prediction step:

$$
\hat{z}_{t|t-1} = A\hat{z}_{t-1|t-1} + Bu_{t-1}, \qquad
P_{t|t-1} = AP_{t-1|t-1}A^\top + Q
$$

Update step:

$$
K_t = P_{t|t-1}H^\top(HP_{t|t-1}H^\top + R)^{-1}
$$

$$
\hat{z}_{t|t} = \hat{z}_{t|t-1} + K_t(x_t - H\hat{z}_{t|t-1}), \qquad
P_{t|t} = (I - K_tH)P_{t|t-1}
$$

Extended Kalman filter idea:

When dynamics/observations are nonlinear, the Extended Kalman Filter (EKF) locally linearizes them (or uses learned linearization, as in EKVAE) and then applies the same predict-update logic.

In this project:

- It provides a clear way to estimate hidden states under uncertainty.
- It is the core inference idea behind EKVAE's latent-state estimation.
- It helps explain why EKVAE may recover dynamics better than purely RNN-based inference.

### 3.3 VAE, KVAE, EKVAE

Definitions:

- VAE (Variational Autoencoder): latent-variable generative model trained with an encoder-decoder and ELBO objective.
- KVAE (Kalman Variational Autoencoder): sequential extension combining VAE-style observation modeling with Kalman-structured latent dynamics.
- EKVAE (Extended Kalman VAE): extends this line with extended-Kalman-style latent inference and neural linearisation of nonlinear dynamics.

Why this matters:

- It shows the progression from static latent modelling (VAE) to sequential latent dynamics (KVAE/EKVAE).
- It explains why EKVAE should improve dynamics learning in partially observed systems.

### 3.4 ELBO, Distortion, and Rate

Definition:

The ELBO is the variational objective used to train latent-variable models when exact likelihood is intractable.

Formula:

$$
\log p(x_{1:T} \mid u_{1:T}) \geq \mathcal{F}_{\text{ELBO}} = -D - R
$$

$$
D = -\mathbb{E}_{q_\phi(z_{1:T} \mid x_{1:T},u_{1:T})}\left[\log p_\theta(x_{1:T} \mid z_{1:T})\right],
\quad
R = \mathrm{KL}\left(q_\phi(z_{1:T} \mid x_{1:T},u_{1:T})\;\|\;p_\psi(z_{1:T} \mid u_{1:T})\right)
$$

Interpretation:

- $D$ measures reconstruction quality.
- $R$ measures posterior-prior mismatch/latent regularisation.

In this project:

- Baseline training target for comparison.
- Key paper claim to test: good ELBO alone does not ensure correct latent dynamics.

### 3.5 Constrained Optimisation (CO)

Definition:

A training reformulation that enforces reconstruction quality and then focuses on compression related to dynamics.

Formula:

$$
\min_{\theta,\psi,\phi} R \quad \text{subject to} \quad D \le D_0
$$

Equivalent Lagrangian:

$$
\mathcal{L} = R + \lambda(D - D_0), \quad \lambda \ge 0
$$

In this project:

- Main mechanism to test against standard ELBO/annealing training.

### 3.6 VHP (Variational Hierarchical Prior)

Definition:

A learnable, hierarchical prior over initial latent states designed to better match the latent-state structure in the data.

Formula:

$$
p_{\psi_0}(z_1) = \int p_{\psi_0}(z_1 \mid \zeta)p(\zeta)\,d\zeta
$$

In this project:

- Reduces over-regularisation and helps avoid unrealistic initial-state sampling.

### 3.7 EKVAE Transition Form

Definition:

State-dependent locally linear Gaussian transition used for latent Kalman-style filtering/smoothing.

Formula:

$$
p_\psi(z_{t+1} \mid z_t,u_t)=\mathcal{N}\left(z_{t+1} \mid F_\psi(z_t,u_t)z_t + B_\psi(z_t,u_t)u_t,\;Q_\psi(z_t,u_t)\right)
$$

In this project:

- Core EKVAE mechanism for nonlinear dynamics modelling with uncertainty handling.

### 3.8 Evaluation Metrics

Prediction accuracy:

$$
\mathrm{MSE} = \frac{1}{NT}\sum_{n=1}^{N}\sum_{t=1}^{T} \lVert \hat{x}_t^{(n)} - x_t^{(n)} \rVert_2^2
$$

Latent-state identifiability:

$$
R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}
$$

In this project:

- MSE checks rollout prediction quality.
- $R^2$ checks whether learned latent variables align with known physical states.

## 4. Scope and Dataset Strategy

Current model scope:

- EKVAE (primary focus)
- One standard DSSM-style baseline
- One Kalman-family baseline
- One additional recurrent/state-space baseline only if needed for comparison

Immediate scope:

- Reproduce the paper on the original toy/controlled datasets first.
- Treat exact numeric match as unrealistic; evaluate trend-level agreement and component effects.
- Keep the first model set narrow so debugging stays manageable.

Initial dataset scope (paper-aligned reproduction):

- Pendulum images (16x16, sequence length 15)
- Reacher angles (sequence length 30)
- Reacher RGB (64x64, sequence length 30)

Interpretation note:

	These paper datasets are useful because they are controlled and easy to interpret.
	Treat exact numeric match as unrealistic; evaluate trend-level agreement and the main component effects.
	Lock the minimum reproducible scope (first models + first dataset).
	Only then test a small number of harder datasets to see whether the method works beyond the paper setting.
	Define the research question, core concepts, scope, and initial approach.
	Run a small set of additional test datasets, then consolidate findings and limitations.
- Prefer longer sequences or noisier real-world series as stress tests.
- If finance is used, treat it as a robustness test rather than a primary benchmark.

If constrained by time/compute/data:

- Prioritize EKVAE + the strongest baselines first, then expand only if the paper results are stable and interpretable.

	Build the first end-to-end pipeline and produce initial comparative results on the paper datasets.

- Stage 4: Communication and presentation.
	Present the work through written reporting and visual summaries for non-specialist and specialist audiences.

## 7. Expected Limitations

- The method may look strong on structured short sequences but weaker on longer or noisier ones.
- Finance-style data is likely to be much harder than the pendulum or reacher benchmarks.
- Short-sequence results should not be treated as proof that the method generalises broadly.
- A failure on harder datasets may reflect dataset difficulty rather than a broken implementation.
